# ChessMate Bot Coach 中文版 v0.5.2

只用于 **Chess.com 明确确认的 Bot / Computer 对局** 的本地实时国际象棋教练。不会自动走棋、点击棋盘，也不会为真人对局提供实时分析。

## 安装 / 升级

1. 解压 `ChessMate-Bot-Coach-ZH-v0.5.2-installable.zip`。
2. 打开 `chrome://extensions`。
3. 开启“开发者模式”。
4. 删除旧版 ChessMate，避免 Chrome 继续指向旧目录。
5. 点击“加载已解压的扩展程序”。
6. 选择刚解压、第一层直接包含 `manifest.json` 的文件夹。
7. 确认扩展版本显示 **0.5.2**。
8. 打开 `https://www.chess.com/play/computer`，刷新一次，然后开始一盘 Bot 对局。

## v0.5.2 窗口更新

- **可改变窗口大小**：拖动浮窗右下角的小型斜线手柄，可以自由调整宽度和高度；大小会保存在本地。
- **正文可滚动**：标题栏保持可见，内容太长时直接在窗口内部上下滚动。
- **中局对手画像移到底部**：实时胜率、Bot 思路、危险提示、对手悬空目标和三个推荐方案优先显示；archetype 放到最下面作为长期战略参考。
- **避免窗口掉出屏幕**：拖动窗口或改变浏览器尺寸时，会把浮窗重新限制在可见区域内。

## v0.5.1 中局与战术功能（继续保留）

### 1. 中局对手画像

ChessMate 会滚动观察最近最多 6 个 Bot 回合，而不是把某个 Bot 永久贴成“进攻型”或“防守型”。它会根据以下局面信号给出当前倾向：

- 将军与强制手；
- 主动吃子 / 交换；
- 对你王区周围格子的压力；
- 子力是否持续进入你的半场；
- 是否频繁后撤、回防、躲开攻击；
- 是否优先改善王安全或化解悬空子。

面板会显示：

- **进攻倾向**：提醒你优先保证王安全、交换最活跃攻击子、不要为了对攻而主动打开自己王前线路；
- **防守 / 反击倾向**：提醒你不要硬冲，寻找弱点、落后发展的子和悬空子，改善最差棋子后再用兵突破；
- **均衡 / 尚未定型**：样本不足或两类信号接近时保持谨慎，不假装知道 Bot 的“心理”。

同时显示置信度、样本量和 1–3 条“为什么这样判断”的证据。

### 2. 对手未保护棋子 / 可利用目标

新增“对手的悬空目标”区域，并在棋盘上用 **蓝色框** 标记对方未受保护的棋子。

系统会区分：

- **可直接安全吃**：当前存在合法吃子，而且吃完后的落点没有立即回吃；
- **已经被你攻击但吃后仍有风险**：会明确提醒先算清楚交换；
- **未保护但暂时吃不到**：作为下一步施压目标，而不是鼓励你强行追子。

这与已有的红 / 黄威胁提示分开：

- 绿：你的落点不受立即攻击；
- 黄：你的落点受攻击，但有己方保护；
- 红：你的落点受攻击且无保护；
- 蓝框：对手棋子当前无人保护。

“对手悬空子”可以在面板底部单独关闭。

### 3. 更耐用的局面追踪与引擎生命周期

v0.5.2 针对中途“突然暂停”做了三层修复：

1. **拖动棋子不再触发引擎销毁**：Chess.com 在拖动过程中可能暂时把棋子从正常 DOM 状态移走。现在这只被视为短暂棋盘不完整，不再被误判成人机身份变化。
2. **支持悔棋 / Takeback**：如果当前棋盘精确匹配 ChessMate 自己之前已经验证过的局面，追踪器会安全回退历史，然后继续分析。不会通过猜测重建任意旧局面。
3. **普通走棋只取消当前搜索，不销毁引擎**：Stockfish/offscreen worker 会保持 warm。只有公平性 guard 真的失效时才完全终止引擎。

此外：

- 仍支持唯一的两步 DOM 跳变恢复，处理“你刚走完 Bot 就立即回复”的情况；
- 同步异常现在进入自动恢复状态，而不是一次异常就彻底停止监听；
- Stockfish worker 如果崩溃，会自动重建一次；若仍失败则回退到本地备用评估器；
- 手动“重置 / 重新同步”会优先保留已经验证的棋局历史，而不是在中局直接把历史清空。


### 4. 推荐方案直接画在棋盘上

Bot 走棋后的最多三个候选方案现在会同时显示在浮窗和棋盘上：

- 棋盘使用细的青绿色箭头；
- 每条箭头带一个小号 **1 / 2 / 3** 圆形编号；
- 编号与浮窗“你的 3 个优先方案”一一对应；
- 深度分析完成后，如果候选顺序改变，棋盘箭头也会一起刷新；
- 你一旦走棋，旧的推荐箭头立即清除，避免把上一回合建议误认为当前建议。

如果候选着法利用了对手未保护棋子，浮窗会把这件事放到理由最前面并加标签：

- **可吃悬空子**：目标未保护，而且吃完后的落点没有立即回吃；
- **悬空子但需计算**：目标虽然未保护，但吃完后你的棋子仍会被攻击；
- **攻击悬空子**：这步本身不吃子，但会直接瞄准一枚无人保护的对手棋子。

这样“对手悬空子”不再只是单独的一块提示，而是会直接进入 1 / 2 / 3 推荐方案的解释。

## Chess.com 允许范围

严格允许：

- `https://www.chess.com/play/computer...`
- Chess.com 的语言前缀 `/xx/play/computer...`
- 明确的 `https://www.chess.com/game/computer/<id>` computer-game 路由及语言前缀版本

明确真人路由（例如 `/play/online`、`/game/live`）继续立即关闭。即使 URL 属于 computer 路由，页面仍必须出现 Bot/Computer 正向信号，不能手动 override。

## 当前引擎限制

如果安装包中没有 Stockfish WASM，会使用完全本地的轻量备用评估器。此时所有 UI、规则、开局、中局画像、战术目标和状态追踪功能都正常，但候选着法和胜率精度低于真正 Stockfish。

## 故障排查

- **拖动棋子时面板短暂不更新**：正常。松开后约 0.2 秒重新读取稳定棋盘。
- **点击 Takeback 后显示“检测到悔棋”**：正常，说明已回到之前验证过的历史状态。
- **显示“同步正在自动恢复”**：先松开所有棋子并等待 Chess.com 动画结束。ChessMate 会继续尝试恢复，不会因一次坏快照销毁引擎。
- **持续无法恢复**：点击“重置 / 重新同步”。v0.5 会优先使用现有合法历史；若页面局面无法对应任何已验证状态，则应重新开始一盘 Bot 对局。
- **显示安全暂停 / 教练关闭**：打开“诊断”查看 pathname、Bot 正向信号和 human signal。安全 guard 不能人工关闭。
