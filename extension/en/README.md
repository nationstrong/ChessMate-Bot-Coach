# ChessMate Bot Coach — English v0.5.2

## Install

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Select **Load unpacked**.
4. Select this folder (the folder containing `manifest.json`).
5. Start a game from `https://www.chess.com/play/computer`.

ChessMate enables analysis only after confirming a supported Bot/Computer game. Analysis runs locally. The panel provides opening context, a live outcome estimate, three candidate plans, move-safety colors, loose-piece targets, and a rolling Bot tendency profile.

The English build uses an English presentation layer over the same v0.5.2 local analysis core as the Chinese build.
